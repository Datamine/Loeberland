          Start a message with / to send it to everyone on the server. For example, /Hello, everyone! Messages can be up to 140 characters. Some servers require an upgrade to send server chat.

          Shortcuts

          Press Esc to see the available shortcuts, then press a key shown in the menu. Activity shortcuts appear when the action is available.

          Open Character, Quests, Collection log, or Help.

          Sit or stand, dance, or roll forward.
          Esc then J
          Hop while your equipped rocket is burning.

          Choose a teleport destination. If you cannot use a tablet, opens the coordinate prompt when the server permits it.

          Use the bicycle, skateboard, or rented motorcycle.

          Do an ollie, kickflip, or 360 shove-it while skateboarding.

          Open exit options or use the Tahoe activity button, return from surfing, or park the Ferrari.
