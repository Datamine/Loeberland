About this editor

Menus and conversations come from canonical JSON definitions. State variants cover quests, ownership and activities. Generic casual conversations are shared across eligible NPCs. Conditions use the same JSON player state as the game. Placements with the same definition and examine text share an entry. Definition details lists their world placements.

Edits stay in this browser until you choose Save to game. The local server writes the entity, dialogue, and text sources under content/. The game reloads content automatically. Export changes also saves a reviewable JSON file. Name changes and NPC/Object conversions apply to every placement using the selected definition.

Refresh the catalog with npm run build:editor. The normal game build refreshes it too.
